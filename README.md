# Atlass E-commerce

> Atlass Corp — Maroc of Design e-commerce automation, scraping, and analytics

## Description
Automation scripts for Maroc of Design e-commerce brand (Amazon Merch, Redbubble, Amazon KDP).

## Structure
- `scrapers/` — Web scraping scripts for market research
- `analytics/` — Sales tracking and metrics
- `automation/` — Order tracking and inventory management
- `data/` — CSV/JSON data outputs

## Getting Started
```bash
git clone https://github.com/ELATLASS/atlass-ecommerce.git
cd atlass-ecommerce
pip install -r requirements.txt
```
